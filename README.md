## Задание 1. Сканирование и поиск уязвимостей

**Установка:** образ с [SourceForge](https://sourceforge.net/projects/metasploitable/) импортирован в гипервизор (VirtualBox/VMware), сеть **Host-Only**, IP `192.168.56.101`.

**Сканирование:**

```bash
nmap -sV -sC -O -p- 192.168.56.102 -oN scan_full.txt
```

`-sV` — версии сервисов, `-sC` — скрипты NSE, `-O` — ОС, `-p-` — все порты, `-oN` — вывод в файл.

**Вывод:** более 20 открытых портов с устаревшим ПО, содержащим известные уязвимости.

### Найденные уязвимости

#### 1. vsftpd 2.3.4 — Backdoor (CVE-2011-2523)

- **Служба:** FTP, порт 21.
- **Суть:** при логине со смайликом `:)` на порту `6200` открывается root-оболочка.
- **Ссылка:** [Exploit-DB #17491](https://www.exploit-db.com/exploits/17491)

#### 2. UnrealIRCd 3.2.8.1 — Backdoor (CVE-2010-2075)

- **Служба:** IRC, порт 6667.
- **Суть:** бэкдор позволяет удалённо выполнять команды с правами сервиса.
- **Ссылка:** [Exploit-DB #16922](https://www.exploit-db.com/exploits/16922)

#### 3. Samba 3.0.20 — usermap_script (CVE-2007-2447)

- **Служба:** SMB, порты 139/445.
- **Суть:** через параметр `username map script` — удалённое выполнение команд, часто root.
- **Ссылка:** [Exploit-DB #16320](https://www.exploit-db.com/exploits/16320)

## Задание 2. Режимы сканирования Nmap

Трафик каждого режима записан в Wireshark (фильтр по IP цели).

| Режим | Команда | Флаги | Открытый порт | Закрытый порт | Особенности |
|-------|---------|-------|---------------|---------------|-------------|
| **SYN** | `nmap -sS -p 1-1000 <IP>` | SYN | SYN/ACK → RST | RST | Быстрый, скрытный, «полуоткрытый» |
| **FIN** | `nmap -sF -p 1-1000 <IP>` | FIN | Нет ответа | RST | Обход фильтров; не работает на Windows |
| **Xmas** | `nmap -sX -p 1-1000 <IP>` | FIN, PSH, URG | Нет ответа | RST | Обход фильтров; «ёлочные» флаги |
| **UDP** | `nmap -sU -p 1-1000 <IP>` | UDP-пакет | Нет ответа / UDP-ответ | ICMP Port Unreachable | Медленный, менее точный |

**Ключевое отличие:** SYN завершает полурукопожатие, FIN/Xmas шлют «неправильные» пакеты (молчание = открыт), UDP работает без соединения и опирается на ICMP.

## Выводы

1. Metasploitable 2 — учебный полигон с множеством критических уязвимостей.
2. Nmap эффективно выявляет порты, сервисы и ОС.
3. Exploit-DB — основной источник готовых эксплойтов.
4. SYN — универсален; FIN/Xmas — обход фильтров (Unix/Linux); UDP — для UDP-сервисов, но медленный.
5. Понимание механики сканирования помогает настраивать IDS.
